# Blender model review

Check that imported controlled geometry retains IDs, units, axes, origins, dimensions, transforms, hierarchy, and accepted revision. Evaluate the packet's declared fidelity: exact mesh requires topology/geometry proof; simplified mesh requires measured deviation within its declaration; envelope proxy is accepted only for its limited inspection/context use and cannot be called face-accurate or final presentation geometry. Check collection/naming rules, missing or duplicated objects, presentation-only additions, material assignment, camera/output requirements, completion receipt, second-process read-back, and file hashes. Apply the render QA profile, separating deterministic metadata checks from independent visual judgment. Visual quality does not excuse engineering drift.
